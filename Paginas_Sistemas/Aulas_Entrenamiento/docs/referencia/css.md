# Referencia: hojas de estilo

**Propósito:** describir qué estiliza cada archivo CSS.
**Cuándo leerlo:** antes de cambiar la apariencia de un bloque.
**Relacionados:** [raiz-y-componentes.md](raiz-y-componentes.md)

| Archivo | Responsabilidad |
|---|---|
| `css/base.css` | Variables `:root` (`--bg-dark`, `--bg-dark-2`, `--bg-navy`, `--accent-green`, `--font-titulos`, `--font-texto`, etc.), reset, `.ae-page`, `.ae-container`, `.section-pad`, `.btn`, `.section-title`, acordeones `details/summary` y base del slider (`.ae-page.is-slider`). |
| `css/navbar.css` | `#navbar`, `.nav-inner`, `.nav-logo`, `.nav-toggle`, `.nav-links`, `.nav-indicator` y comportamiento responsive. |
| `css/inicio.css` | Hero de inicio: `.hero`, `.hero-img`, `.hero-overlay`, `.hero-content`, etc. |
| `css/plataformas.css` | Plantillas "Quiero empezar" / "Ya soy miembro": `.ae-page .access-hero`, `.access-hero-panel`, `.platform-select-card`, etc. |
| `css/connect.css` | Pasos tipo "pill" (`.pill-steps-grid`, `.pill-step-card`), tablas y elementos de Connect. |
| `css/dudas.css` | `#dudas`, títulos y FAQ. |
| `css/sobre-nosotros.css` | `#sobre-nosotros` (banner y contenido). |
| `css/footer.css` | `footer`. |
